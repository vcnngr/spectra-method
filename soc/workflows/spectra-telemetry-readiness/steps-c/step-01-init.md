# Step 01 - Telemetry Intake

## STEP GOAL

Define telemetry sources, owners, collection paths, parser status, and review objectives.

## MANDATORY EXECUTION RULES

- Confirm read-only access.
- Identify source type, retention, volume, parser, and destination.
- Agent Autonomy Protocol: block log deletion, pipeline disabling, retention changes, and tampering.

## REQUIRED OUTPUT

Append source inventory, owner map, data access method, sample availability, and review constraints.

SUCCESS: Telemetry review scope is clear.

FAILURE: Source ownership or access method is unknown.
