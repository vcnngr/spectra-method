# Step 06 - Detection Gap Map

## STEP GOAL

Translate telemetry gaps into detection and investigation impact.

## MANDATORY EXECUTION RULES

- Link each gap to missed questions, ATT&CK techniques, or response delays.
- Separate data-source gaps from rule-quality gaps.
- Agent Autonomy Protocol: no claim of detection coverage without data proof.

## REQUIRED OUTPUT

Append gap, affected detection, required field/source, impact, priority, owner, and validation test.

SUCCESS: Telemetry gaps become engineering tasks.

FAILURE: Gaps are too generic to assign.
