# Step 07 - Report And Handoff

## STEP GOAL

Finalize identity detection review and hand off improvements to SOC, IAM, and GRC owners.

## MANDATORY EXECUTION RULES

- Redact identities where not required.
- Route detection work to `spectra-detection-lifecycle`.
- Route telemetry gaps to `spectra-telemetry-readiness`.
- Agent Autonomy Protocol: no secrets, tokens, or bypass instructions in the final report.

## REQUIRED OUTPUT

Append executive summary, priority gaps, quick wins, long-term controls, detection backlog, and retest plan.

SUCCESS: Owners can improve identity defense from the artifact.

FAILURE: Output is only descriptive and not actionable.
