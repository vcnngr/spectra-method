# Step 01 - Identity Scope Intake

## STEP GOAL

Define identity platforms, admin boundaries, telemetry sources, and allowed review methods.

## MANDATORY EXECUTION RULES

- Confirm the engagement permits SOC identity review.
- Identify read-only evidence sources and any privileged consoles.
- Agent Autonomy Protocol: block credential attacks, token theft, MFA fatigue, and real-user takeover.

## REQUIRED OUTPUT

Append identity platforms, tenants/domains, admin groups, test accounts, log sources, and prohibited actions.

SUCCESS: Identity scope and data sources are explicit.

FAILURE: Platform, tenant, or privilege boundary is ambiguous.
