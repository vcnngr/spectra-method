# Step 07 - Cloud Incident Report

## STEP GOAL

Finalize cloud incident timeline, findings, actions, evidence, and improvement plan.

## MANDATORY EXECUTION RULES

- Keep secrets, tokens, and sensitive resource identifiers minimized.
- Distinguish confirmed facts from hypotheses.
- Agent Autonomy Protocol: no evasion, persistence, or cleanup guidance.

## REQUIRED OUTPUT

Append timeline, affected assets, evidence index, containment decisions, recovery status, detection gaps, and lessons learned.

SUCCESS: Incident response artifact supports leadership and engineering action.

FAILURE: Report cannot explain impact, decisions, or residual risk.
