# Step 05 - Eradication And Recovery

## STEP GOAL

Plan removal of unauthorized access, restore secure configuration, and validate recovery.

## MANDATORY EXECUTION RULES

- Separate eradication plan from live execution unless approval is recorded.
- Preserve before/after evidence.
- Agent Autonomy Protocol: no destructive cleanup, audit tampering, or unapproved credential rotation.

## REQUIRED OUTPUT

Append root cause candidates, remediation steps, validation tests, residual risk, and monitoring needs.

SUCCESS: Recovery can be verified.

FAILURE: Remediation lacks evidence or rollback.
