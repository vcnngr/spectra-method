# Step 04 - Containment Plan

## STEP GOAL

Prepare safe containment options with approval gates, rollback, expected impact, and responder access protection.

## MANDATORY EXECUTION RULES

- No automatic containment.
- Require explicit approval for identity revoke, key rotation, network block, workload isolation, or SaaS session reset.
- Agent Autonomy Protocol: block actions that could lock out responders or destroy evidence without approval.

## REQUIRED OUTPUT

Append containment options, blast radius, approval owner, rollback plan, evidence risk, and execution checklist.

SUCCESS: Operators can choose safe containment.

FAILURE: Plan risks production outage or evidence loss.
